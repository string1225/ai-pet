# 宠物与学习框架

## 加入第二种宠物

1. 在 `PetRegistry` 的初始化处注册 `PetDefinition`。ID 一经发布应保持不变，它也是存档键的一部分。
2. 实现 `PetRenderer.draw(Canvas, PetState, x, y, time, reaction)`。绘图坐标以宠物中心为原点，参考 `SnakeRenderer`；`time` 驱动动画，`reaction` 表示 0～1 的互动爱心强度，`state.sleeping` 控制睡眠姿势。
3. 在 `RendererRegistry` 注册相同 ID 的绘制器。缺失或重复注册会明确报错，避免静默展示错误宠物。
4. 图鉴自动显示新宠物。点击另一种宠物时保存当前状态，载入另一种的独立存档，首次进入从蛋开始。

```java
// PetRegistry
register(new PetDefinition("little_turtle", "小乌龟", "团团",
    "喜欢慢慢散步和听故事的小乌龟。", 0xFF8DAE83, 18, 16));

// RendererRegistry
register("little_turtle", new TurtleRenderer());
```

`PetEngine` 从当前物种配置读取喂食和陪玩增益，题库和小屋使用同一套流程。当前产品只注册了小蛇，测试中额外注册测试龟验证扩展能力。

## 养成规则

- 蛋从 0% 开始，每个正确答案增加 25% 温暖。到 100% 记录出生时间。
- 喂食答对一题并完成后，点心消耗一份，小蛇饱腹 +22、心情 +3、亲密度 +2。库存不足时由答题现做一份；满腹或睡眠不扣库存。
- 水同样答对一题后完成，不消耗点心，心情 +2、精力 +3。
- 陪玩直接进入一道按学习方案分配的题目，完成后心情 +18、精力 -6、亲密度 +4。
- 清洗答对一题并完成后，清洁 +25、心情 +3、亲密度 +2。清洁度初始 80，最高 100，满清洁或睡眠时不开始清洗。
- 每个正确答案获得一颗金色知识星；完成普通学习回合额外获得两份点心、心情 +5、亲密度 +4。照顾回合不发放普通学习完成奖励。
- 每 30 亲密度升一级。学习进度和养成数值相互独立。
- 每经过完整一小时：饱腹 -3、心情和清洁 -2；清醒精力 -2，睡眠精力 +12。一次离开最多计算八小时；饱腹和清醒精力最低 20，心情和清洁最低 25，没有死亡或惩罚。
- 点击小蛇的奖励有 800ms 间隔，抚摸不增加亲密度。

照顾与学习状态通过 `PetEngine` 执行，再立即存档。错误答案不调用奖励方法；同一题答对后禁用选项并锁定本题，窗口重绘保留答对状态，避免旋转后重复领取奖励。`Lesson.finished` 与当前回合身份共同防止完成按钮旧回调重复发奖。照顾未完成时退出，仅保留已获得的答题星星。

## 双色星星与装扮

`RewardCatalog` 是两个兑换入口共用的纯 Java 商品目录，定义价格、描述与效果。`RewardShop` 展示金色知识星、绿色成长星及其来源，每次任选一种支付，同价且不混扣。知识星从当前宠物的 `stars` 扣除，`learned` 里的历史累计不变；同步保存失败时重新加载已保存状态。成长星沿用家庭账本与礼物队列。

星星挂饰 6 星、云朵地毯 8 星、花开盆栽 10 星，保存到 `decorations` 和 `equippedDecorations`；只能购买一次，免费切换布置。`RoomView` 在布置组合变化时重绘缓存背景。成长果实 10 星增加 30 亲密度，按现有等级规则立刻升一级；点心和派对也支持两种星星。

## 学习内容

0.2.0 增加 `LearningSettings`，由 `FamilyStore` 随家庭记录同步原子保存。三档难度分别应用于语文、数学、英语；语文包括拼音与识字，内部比例单独设置。默认语文/数学/英语为 40/40/20，拼音占语文 50%。综合回合使用按比例配额与随机取整，整数配额保持精确，小比例学科在多轮中也能出现；单题活动按权重抽取。0% 的学科不会出题。词库不足整轮数量时分批打乱并复习，避免生成循环无法结束。

`QuestionBank.session(subject, count, settings)`、`mixed(count, settings)` 和 `incubation(warmth, settings)` 统一使用课程设置。所有题目在开始回合时生成，新设置不会重写已开始的回合。基础旧方法仍可独立使用，方便原有调用者与测试。

`Question` 包含学科、题干、辅助线索、四个选项、答案、提示和朗读内容。选项不可变，正确答案仅出现一次。

- 数学按规则生成：启蒙/基础/挑战上限分别为 5/10/20；加法操作数与结果不超过上限，减法结果非负。
- 拼音：12 个音节，涵盖单韵母、复韵母、鼻韵母和翘舌声母，例如 b + ā、sh + uǐ、n + iú。
- 汉字：基础 16 个常用字，以拼音和中文线索帮助识读；启蒙取前 8 个，挑战使用 12 个词语补字题。
- 英语：基础 16 个常见词，涵盖水果、动物、颜色和日常物品；启蒙取前 8 个，挑战反向识读英文选中文。
- 普通回合三题，题干不重复；孵化按四个学科顺序出题，中断后只生成尚未完成的学科。
- 喂食、喝水、陪玩、清洗都通过 `mixed(1, settings)` 抽题，使用当前课程难度与比例。

扩充词库可编辑 `QuestionBank` 的表；新增学科需要同时增加 `Subject` 和 `QuestionBank.next` 的实现，并检查孵化是否仍采用四个学科。

## 存档与中断

0.2.0 的家庭记录在 `family_home` 中，与 `pet_home` 的各物种存档独立。`FamilyStore` 对 UI 和后台结算使用同步访问、整体 JSON 原子提交，并在保存失败时回滚内存状态。

生活任务提交快照保存标题、奖励和所属日期，确认只发放一次；改名、停用或修改奖励不重写历史。绿色成长星通过可审计账本计算；金色知识星是宠物的可用余额，分科学习记录保存累计成绩。娱乐 App 使用事件经过 `UsageTimeline` 计算同一包前台 Activity 的时间并集，按日期与规则有效区间切分，用 `billed` 记录已结算单位，支持幂等刷新。修改/停用前先同步旧规则；没有启用规则时不读取前台事件，并取消后台周期作业。

礼物购买先在家庭记录中提交扣星与待送达队列；宠物通过 `appliedGifts` 记录已经收到的 ID，同步保存宠物后才确认家庭队列送达。中断可重试，相同 ID 不会重复加点心或亲密度。旧宠物 JSON 没有这个字段时默认空集合；新宠物和已有物种都通过同一交付接口处理。

家长 PIN 使用随机盐及 PBKDF2-HMAC-SHA256，家长会话只保存在 Activity 内存中，离开应用、退出家长页面或 5 分钟后锁定。每次敏感变更重新核对会话有效期；手动更新检查、下载、安装与宠物重置都复用同一门槛。导出家庭 JSON 时删除 PIN 盐与摘要。

SharedPreferences 文件 `pet_home`：`active_species` 标记当前宠物；`pet.<speciesId>` 各保存一个 version=2 的 JSON，兼容旧版默认清洁 80、装扮集合为空。新宠物自动使用物种默认名字；不同物种的星星、点心、装扮、名字、出生时间和学习统计各自保留。

每次正确答案和照顾立即保存，暂停应用时再次保存；损坏 JSON 回退到可用状态。学习回合自身只保存在内存中，杀进程后未完成回合不会发放完成奖励，但已经得到的星星、题目统计和孵化温暖保留。再次孵化从剩余进度继续。

## 界面和设备

界面由 Android 原生控件和 Canvas 绘本场景组成，没有 WebView。场景以 1000×600 坐标缩放。房间家具提供虚拟无障碍按钮，学习和设置使用原生按钮，可由 UIAutomator 查询。

宽度 840dp 以上使用左侧宠物资料和右侧小屋；窄屏资料区缩成上方横排头像与养成状态。处理系统栏安全区域，弹窗可滚动。Android 13 以上使用系统返回回调，旧版处理返回按键。家具背景缓存为位图，弹窗打开或应用失去焦点时暂停房间动画。

TTS 使用中文或英文系统语音数据。声音不可用时给出文字提示；题目和奖励不依赖语音服务。

Android 11 以上通过 manifest 的 `TTS_SERVICE` 查询声明发现语音引擎，遵循 [Android TextToSpeech 文档](https://developer.android.com/reference/android/speech/tts/TextToSpeech)。
